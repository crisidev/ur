# The notification review set: twenty notifications, each in every view the
# watch shows one in, in a dark theme (ARCADE), a light one (HANDHELD), and
# the dim white-on-black look. For reviewing (and re-reviewing) how
# notifications look; not an approved-screenshot script.
#
#   cargo run --release -- notifications.txt --out ../tmp/notify-review
#
# Each is a line as Gadgetbridge sends it (`gb`), through the firmware's
# parser. Every name, number, and message is invented; the shapes are
# typical Android ones (see the list below). The watch shows only `src`
# and the sender (or, without one, the title): subject and body are read
# for images, never shown. They're here anyway, as the phone sends them.
#
# Each notification arrives three times, once per section, as each view
# needs its own way in:
#
#   1. quiet:   with the screen off: the whole screen, dim (always white on
#               black), the sender big if it's short.
#   2. banner:  with the clock on screen: the banner over its bottom rows;
#      history: then swiped down to: the first page of the history.
#               Both shot in ARCADE (the evening's theme) and HANDHELD
#               (its colours on the same frame, as `screenshot.py --theme`).
#   3. dim:     in the quiet night: it waits; the button shows the banner,
#               dim; swiped down to, the history page, dim.
#
# So a change to the set goes in all three sections, in the same order.
# Shots are named NN-KIND-VIEW-THEME.png.
#
#   01 sms-short          Messages: Ida
#   02 signal             Signal: Ada Lovelace
#   03 sms-number         SMS Message: +47 912 34 567
#   04 code-2fa           Messages: UrBank
