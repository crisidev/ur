# Themes

How the watch looks: each theme draws every screen in its own way, with
one or more colour schemes, which Settings' THEME row picks between. A
build has the themes its features name (see
[AUTHORING-THEMES.md](../../AUTHORING-THEMES.md), which is also how to
make one); a release's `ur` has Retro, and every other theme has a
package of its own. Each row's "Try it" opens the simulator in your
browser, showing that theme.

| Theme | Feature | Schemes | Live |
|---|---|---|---|
| [Retro](retro/) | `theme-retro` (the default) | ARCADE, TERMINAL, TOKYO NIGHT and TOKYO STORM by night; HANDHELD, PARCHMENT and TOKYO DAY by day | [Try it](https://jonhoo.github.io/ur/sim/?theme=retro) |
| [Living Tokyo](living_tokyo/) | `theme-living_tokyo` | LIVING TOKYO and LIVING STORM, by night only | [Try it](https://jonhoo.github.io/ur/sim/?theme=living_tokyo) |
